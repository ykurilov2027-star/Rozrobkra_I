# Порівняння семантичного пошуку та BM25

`queries.json` містить 15 запитів із колекції та поза нею, типом запиту,
очікуваним документом і потрібними метаданими-фільтрами. `run.py` проганяє
семантичний пошук і BM25 по тих самих фрагментах, рахує hit@1/hit@3 та
вимірює час пошуку. У семантичний час входить кодування запиту.

Із кореневої папки `pr5` запустіть:

```bash
python compare/run.py
```

Скрипт також порівнює базову конфігурацію E5 із єдиною зміненою умовою:
відсутні префікси `query: ` і `passage: `. За обох прогонів не змінюються
колекція, розмір фрагмента, запити, фільтри чи top-k. Агреговані метрики та
результат кожного запиту записуються в `findings.md`. Значення у звіті
формуються реальним запуском на локальній моделі, а не задаються вручну.

Метрики hit@1/hit@3 розраховуються лише за запитами, для яких задано
очікуваний документ. Для запиту поза колекцією звіт показує перший
результат і його оцінку, але не зараховує його як позитивне влучення.
